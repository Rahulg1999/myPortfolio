How I build

01 / Practice
A

Offline is the default

The network is treated as a bonus. Local database as the source of truth, background sync that survives the app being killed, and conflicts resolved without losing an operative's afternoon of work.

  • Drift · sqflite · ObjectBox
  • WorkManager & foreground services
  • Conflict-aware sync queues
  • Unsynced counts on the dashboard
B

Evidence, not vibes

Compliance work needs a record of who said what, where and when. Pin-level photo evidence on drawings, on-image markup, captured signatures, dynamic forms driven by a rule engine.

  • Pin placement on scanned drawings
  • Signatures & re-signing intervals
  • Geofencing · biometrics · QR
  • MFA / OTP, multi-tenant access
C

AI where it pays rent

Gemini put on real internal problems: an assistant inside an API-monitoring tool that answers questions and drafts test cases and documentation, plus a dozen focused tools on the same API.

  • Google Gemini API
  • Prompt engineering for repeatable output
  • Document Q&A, image analysis
  • Chrome MV3 automation

HRM OTM

Flutter · multi-tenant HR & leave

Shipped

A multi-tenant HR app running as a two-client, multi-flavor build from one codebase, with separate application IDs and signing per client.
